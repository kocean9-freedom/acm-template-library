## 分层口径

先按正式队的解题数降序、罚时升序恢复排名，再按每站公开的金/银/铜名额切分队伍区间：

- **铜牌核心**：铜牌区通过率不低于 65%，应进入低罚时稳定题包。
- **银牌突破**：银牌区比铜牌区明显更常通过，或在银牌区形成多数，是典型第 k+1 题。
- **桥接题**：铜牌区已经较常见、银牌区近乎必做，训练重点是一次通过和低罚时。

阈值只生成候选，最终仍结合题解、知识门槛、证明难度和实现风险复核。奖牌是发给队伍的，不是发给题目的，因此报告中的标签只能用于训练决策。

## 正确使用方式

1. 选一站，只看铜牌核心题，做 90 分钟限时稳定包。
2. 对照报告区分“算法不会”和“读错、证明缺失、边界、实现”造成的罚时。
3. 从银牌突破中只选一条主线，15 分钟找压缩对象，35 分钟没有闭合推导就止损。
4. 做报告给出的同构题，口述真正相同的核心转化、最小状态和证明抓手。
5. 一周后回做原题，并把能复用的 10–30 行沉淀到模板库。
